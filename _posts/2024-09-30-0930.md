# <a id="section1"></a>1. 수집 모델 선정
### 모델의 조건
- 어플리케이션을 자유롭게 설치할 수 있을 것 (헬스 커넥트로 동기화할 수 있을 것)
- 심박 센서를 활용할 수 있을 것
- 예산 (기기 총 예산 9만원 이내)에 포함될 것 

### 구매 과정의 어려움
우선 예산이 적었고, 우리가 구매하려던 모델 fitbit은 구매대행사와, 판매자, 현지 상황, 배송 등에 의해 계속 구매할 수 없었다.   
그래서 우리의 결론은 조금 더 비싸지만 조건에 부합하고 향후 개발에 어려움이 없을 것 같은 모델인 갤럭시 핏 3를 구매하기로 했다.    
이 경우 데이터 수집에 어려움을 겪을 수 있었는데, 다른 방법으로 기기를 마련하는 것으로 대안을 찾았다.    
(1) 김석영 - 원래 사용하던 애플 워치 사용   **애플 워치 7**   
(2) 추설우 - 조건에 부합하는 예전 갤럭시 워치를 찾아옴 **갤럭시 워치 4**   
(3) 권성혁 - 캡스톤디자인 예산으로 구매 **갤럭시 핏3**   
(4) 이윤서 - 사비로 중고품 개인 구매   
(5) 김규리 - 사비로 중고품 개인 구매 **갤럭시 워치 6**   

# <a id="section2"></a>2. 데이터 구축 명세
## 데이터 수집 명세서 작성  
아래 내용은 요약본임    

데이터 수집 기간: 앱 구축 완료일 ~ 
데이터 수집 인원: 김석영 외 4인
데이터 수집 방법: 

(1) 수집용 앱을 통해 자동화된 데이터(심박수, 조도, 소음, 공부 누적 시간, 공부한 시간대(타임스탬프)) 자동적으로 수집됨
(2) 수집용 앱을 통해 반자동화된 데이터(집중 여부, 수면 시간, 낮잠 여부, 활동(뭘 했는지), 카페인 섭취 여부, 전자기기 사용 여부, 음악 청취 여부)를 기입하면 자동적으로 수집됨 
(3) 앱을 통해 수집된 데이터가 DB(구글 스프레드 시트)에 작성됨
(4) 필요에 따라 반자동화된 데이터를 개개인이 수동적으로 수정함

수집 라벨 및 수집 방법:  
기본적으로 20분마다 새로운 데이터 추가 
(1) 자동으로 수집함:    
수집 앱에서 해당 타임 슬롯 안으로 평균을 내서 db로 전달
- 심박수 : 워치에서 수집 > 삼성 헬스 > 헬스 커넥트 > 수집 앱 > db
- 조도 : 수집 앱을 통해 휴대폰 센서로 수집 > db 
- 소음 : 수집 앱을 통해 휴대폰 센서로 수집 > db 
- 공부누적시간 : 수집 앱을 통해 시간 계산 > db 
(2) 반자동으로 수집함:   
사용자가 한번 설정해놓으면, db로 타임 슬롯마다 db로 전달
- 집중 여부: 집중했으면 1, 아니면 0
- 수면 시간: N시간 M분으로 수집, 앱에서 N*60+M분으로 저장하여 db로 전달함
- 낮잠 여부: 낮잠 30분 이상은 2, 낮잠 30분 이하는 1, 낮잠 자지 않았을 경우 0
- 활동: 어떤 활동을 했는지 개개인마다 클래스를 정해 작성
- 카페인 섭취 여부: 섭취했으면 1, 안했으면 0
- 전자기기 사용 여부: 전자기기를 사용한 활동이었으면 1, 아니었으면 0
- 음악 청취 여부: 음악을 들었으면 1, 아니었으면 0
